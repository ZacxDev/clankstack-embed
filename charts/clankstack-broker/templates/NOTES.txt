clankstack-broker is installed as "{{ .Release.Name }}" in namespace "{{ .Release.Namespace }}".

In-cluster URL:
  http://{{ include "clankstack-broker.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}

{{- if .Values.ingress.enabled }}
Public URL:
  http{{ if .Values.ingress.tls }}s{{ end }}://{{ .Values.ingress.host }}
{{- else }}
Port-forward to try it locally:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "clankstack-broker.fullname" . }} 8090:{{ .Values.service.port }}
{{- end }}

Create an embed (management API needs the sk_ key):
  SK=$(kubectl -n {{ .Release.Namespace }} get secret {{ include "clankstack-broker.secretName" . }} -o jsonpath='{.data.BROKER_SK}' | base64 -d)
  curl -s -X POST http://localhost:8090/v1/embeds \
    -H "Authorization: Bearer $SK" -H 'Content-Type: application/json' \
    -d '{"agent":"My Agent","allowed_origins":["https://example.com"],
         "daily_token_budget":50000,"per_session_msg_budget":20,
         "per_session_tok_budget":8000,"sessions_per_min":20,
         "gateway_url":"http://<agent-gateway>:18789","hooks_token":"<HOOKS_TOKEN>"}'
  # -> returns { "id", "publishable_key": "pk_live_..." }

Then drop it on any page (allowed origin):
  <script type="module"
    src="https://cdn.jsdelivr.net/npm/@clank-stack/agent-embed/dist/agent.js"></script>
  <clankstack-agent publishable-key="pk_live_..." endpoint="<broker public url>"></clankstack-agent>
